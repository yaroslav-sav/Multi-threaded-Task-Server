# Multi-threaded-Task-Server

TCP-сервер на Python, обслуживающий нескольких клиентов
одновременно. Все клиенты работают с одним общим списком задач.

## Состав проекта

- `server.py` — TCP-сервер, принимает подключения, хранит общий список задач.
- `client.py` — клиент с командами.
- `protocol.py` — протокол, правила обработки сигналов

## Запуск

**Сервер:**

запуск через терминал:
python3 server.py


**Клиент** 

(в отдельном терминале):
python3 client.py


## Команды клиента

| Команда | Действие |
|---|---|
| `/add <текст>` | добавить задачу |
| `/list` | показать все задачи |
| `/done <номер>` | отметить задачу выполненной |
| `/quit` | выйти |

## Как реализована одновременная работа клиентов

Каждое входящее подключение обрабатывается в отдельном потоке:
Основной поток сервера только принимает соединения. Каждый клиент
обслуживается своим потоком `handle_client`, поэтому клиенты не блокируют
друг друга. Список задач `LIST_TASKS` общий для всех потоков.


## Где и зачем используется синхронизация

Список задач общий для всех клиентов, поэтому его меняют под threading.Lock,
иначе два клиента одновременно добавят задачу и один результат потеряется. 
Копия списка делается под локом, отправка — вне лока, чтобы не блокировать других.
